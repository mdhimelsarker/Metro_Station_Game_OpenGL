# Metro Station Game using OpenGL

## 📌 Project Overview

**Metro Station Game using OpenGL** is a Python-based graphics project that demonstrates a metro station game environment using OpenGL. The project focuses on computer graphics and visual scene rendering.

## 🎯 Objectives

- To develop a graphical application using Python and OpenGL.
- To demonstrate fundamental computer graphics concepts.
- To create and render a visual environment using OpenGL.
- To gain practical experience with graphics programming.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Graphics Library:** OpenGL
- **Development Environment:** Visual Studio Code


## ⚙️ Requirements

Make sure Python is installed on your computer.

Required Python libraries may include:

- PyOpenGL
- PyOpenGL-accelerate (optional)

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/mdhimelsarker/Metro_Station_Game_OpenGL.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Metro_Station_Game_OpenGL
   ```

3. Install the required libraries:

   ```bash
   python -m pip install PyOpenGL PyOpenGL_accelerate
   ```

4. Run the game:

   ```bash
   python Game.py
   ```
